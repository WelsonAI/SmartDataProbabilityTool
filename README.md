# Smart Data & Probability Tool

Interactive classroom manipulatives for Malaysian primary Mathematics (SK/SJKC), Years 4–6. The site is a teaching tool rather than a question bank: pupils build, drag, compare and simulate while the representation updates immediately.

## Included tools

- Year 4: pictograph builder, bar-chart builder, and matching views for the same data.
- Year 5: pie-chart explorer and a draggable mode/median/mean/range laboratory.
- Year 6: 45° pie-chart builder and a probability simulator using the five textbook chance categories.
- Bahasa Melayu, 中文 and English interfaces.
- Pointer dragging, touch-friendly tap alternatives, keyboard controls and teacher-defined demonstration data.

## Curriculum boundaries

The activities follow the current KSSR Semakan data and probability standards. They do not generate independent story questions or introduce topics outside the stated standards.

- [DSKP Mathematics Year 4 — Data Handling](https://anyflip.com/iaciy/yyli/basic/51-90)
- [DSKP Mathematics Year 5 — Pie charts and statistical measures](https://fliphtml5.com/zwryf/fygq/05_DSKP_KSSR_SEMAKAN_2017_MATEMATIK_TAHUN_5/76/)
- [DSKP Mathematics Year 6 — Pie charts and probability](https://asiemodel.net/wp-content/uploads/2022/08/3.-DSKP-MATEMATIK-TAHUN-6_isbn.pdf)

## Run locally

Open `index.html` in a modern browser. No build step or server is required.
